                    Import a checklist (for example your licensed IS 17802 checklist)

                    IS 17802 is a paid BIS standard, so its clauses are not built in. Paste CSV with a header row containing reference and requirement, and optionally title, category, wcag, verification and source. Separate several WCAG criteria with semicolons.
